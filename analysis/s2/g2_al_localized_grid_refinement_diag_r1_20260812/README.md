# S2/G2 局域 108 原子实空间网格加密诊断

本诊断只读复用已提交的 `S2-20260811-001` 96³ KS-NL 电荷密度和固定的
`r08_eta100_complementary` 投影候选，不启动新的 KS 求解器，也不改写 R2 的科学拒绝。

参考密度与投影密度分别以周期傅里叶重采样从 96³ 加密到 128³。两套网格均使用
16 个等间隔亚网格相位，以相同 DFTpy Hartree、外势、PBE XC 和固定 WT 算子重新
计算平移能量和循环中心差分伪力。

96³ 对照复现了原有问题：参考、候选和投影新增最大伪力分别为
`0.00289281854`、`0.00904391050` 和 `0.00615199957 eV/Å`。128³ 后三者分别降为
`7.17594e-6`、`2.60518e-6` 和 `6.27785e-6 eV/Å`。相应能量峰峰值为
`0.000242789`、`0.0000767638` 和 `0.000169462 meV/atom`。

傅里叶重采样前后的参考电子数变化为 `-1.14e-13 e`，投影电子数变化为 0。
因此旧伪力失败主要来自 96³ 分析网格离散误差；128³ 诊断值远低于原
`0.002 eV/Å` 门。

本结果是用户授权后的探索性、事后诊断，不是预注册验收。它不改变旧 R2 状态，
也不处理 2171–2172/2173 的秩失败。正式接受仍需新 revision 预注册 128³ 或更密
网格口径，并把有效子空间/冗余模态门单独闭合。

# S0 reproducibility protocol

This protocol fixes the conventions used by all experiments after G0. Native
program output is retained unchanged; normalized tables and JSON records use the
units below.

## Units and symbols

| Quantity | Symbol | Stored unit |
|---|---|---|
| Length and displacement | `r`, `a` | angstrom (`A`) |
| Cell volume | `V` | `A^3` |
| Electron density | `n(r)` | electron / `A^3` |
| Total energy | `E_total` | eV |
| Per-atom energy | `e_total` | eV/atom |
| Force | `F` | eV/A |
| Stress | `sigma` | GPa |
| Temperature | `T` | K |
| Time | `t` | fs |

Atomic units may be used inside numerical kernels, but every conversion must be
performed in a named function and tested against a recorded constant. A result
file must declare its unit; unitless energy, force, stress, or density fields are
not accepted.

## Energy convention

- `E_total` is the final converged total energy reported by the named electronic
  structure program for the exact structure, pseudopotential, XC, KEDF, and
  convergence settings in the experiment metadata.
- `e_total = E_total / N_atoms`.
- Energy differences compare configurations with identical composition and the
  same pseudopotential/XC/KEDF setup unless the comparison explicitly defines a
  reference reaction.
- Cohesive, formation, defect, and phase energies require an explicit equation
  and reference experiment IDs before their first use. No implicit isolated-atom
  or elemental reference is allowed.
- Printed precision is not an uncertainty estimate. Reproducibility tolerance is
  evaluated from unrounded parsed values.

## Identifiers and immutable inputs

- Experiment ID: `S<stage>-YYYYMMDD-NNN`, for example `S0-20260805-002`.
- Structure ID: `<element-or-system>_<prototype>_<variant>`, lowercase ASCII,
  for example `al_fcc_eq`.
- Every run records the Git commit, program version, pseudopotential SHA-256,
  structure ID, XC, KEDF, MPI ranks, convergence settings, and input checksums.
- A random seed is mandatory whenever stochastic sampling, initialization, or
  training is used. Deterministic calculations record `random_seed: null`.
- An existing experiment directory is immutable. Re-runs always receive a new
  experiment ID.

## File formats

- Human decisions and protocols: Markdown, UTF-8.
- Small machine-readable metadata and summaries: JSON, UTF-8, sorted keys when
  generated by project scripts.
- Rectangular scalar tables: TSV with a header and explicit unit-bearing column
  names where practical.
- Large arrays: NPZ or HDF5 with units and axis meanings in metadata.
- Raw program output is retained for audit but is not parsed manually into an
  acceptance table.

## Acceptance and reporting

- A calculation is valid only when the program convergence marker is present and
  the parser exits successfully.
- Failed samples remain in denominators and experiment ledgers.
- Threshold changes must be committed before the evaluated run.
- Raw output, parsed values, metadata, and input checksums together form the
  minimum evidence bundle.

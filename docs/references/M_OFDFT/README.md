## 目录结构

- 本地受控证据包 `pdfs/`：可合法获取的全文 PDF（不随仓库发布）。
- 本地受控证据包 `text/`：由 PDF 提取的全文文本，供检索和复核（不随仓库发布）。
- 本地受控证据包 `notes/`：逐篇中文精读工作笔记（不随仓库发布）。
- 本地受控证据包 `qa/`：PDF 渲染抽查和误下载隔离文件；不属于正式文献包，也不随仓库发布。
